# R387 AI Decorator

**Prompt-driven level decoration for Geometry Dash.**

Describe a theme, preview a local pattern, and place it directly in the editor. Includes automatic keyword-based style detection, Castle / Forest / City / Circuit / Space presets, adjustable object limits, and a button to remove the last generated batch.

This version works offline and does not require an API key. Its generator makes geometric arrangements using basic solid block objects, so always review collision and placement before saving. It is not yet connected to an online AI model and does not automatically create custom textures, color channels, or trigger systems.
